# QR Menu — электронное меню ресторана по QR-коду

Веб-приложение на Flask и MySQL: гости сканируют QR-код на столе и открывают меню ресторана в браузере. Персонал ведёт меню в админ-панели. Одна установка обслуживает несколько ресторанов, у каждого свой адрес (`/<slug>`).

## Возможности

**Для гостей**
- Меню ресторана с категориями, поиском, описаниями, граммовкой и фото блюд
- Корзина для подсчёта заказа (`/<slug>/cart`)
- Интерфейс на русском, английском и кыргызском языках
- Страница-заглушка, если ресторан временно отключён

**Админ-панель** (`/admin`)
- Вход по email и паролю (хеши Werkzeug), CSRF-защита форм, сессия на 8 часов
- Рестораны: создание, редактирование профиля (контакты, часы работы, карта 2ГИС, логотип), включение и отключение
- Категории: добавление, переименование, удаление, сортировка перетаскиванием
- Блюда: добавление, редактирование, загрузка фото, отметка «нет в наличии»
- Пользователи: роли `developer` (все рестораны) и `user` (только назначенные рестораны), блокировка
- QR-код: генерация с логотипом ресторана, предпросмотр, выгрузка готового PDF для печати
- Дашборд с аналитикой: посещения меню и добавления блюд в корзину

## Технологии

Python, Flask 2.3, MySQL 8 (`mysql-connector-python`), Jinja2, Tailwind CSS, ванильный JavaScript (ES-модули), Pillow, qrcode, ReportLab, pypdf.

## Установка

### 1. Требования

- Python 3.10–3.12. На Python 3.13 и новее `Pillow==10.0.1` не устанавливается: поставьте свежую версию командой `pip install -U Pillow`.
- MySQL 8.x или MariaDB 10.5+

### 2. Код и зависимости

```bash
git clone https://github.com/kubaofficialpage/qr-menu-restaurant-flask.git
cd qr-menu-restaurant-flask
python -m venv venv
```

Активируйте окружение:

```bash
# Windows (PowerShell)
.\venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### 3. База данных

Создайте базу и все таблицы одной командой:

```bash
mysql -u root -p < sql/schema.sql
```

Файл `sql/schema.sql` содержит полную актуальную схему. Остальные файлы в `sql/` — миграции для баз, созданных старыми версиями. На новой базе их запускать не нужно.

Параметры подключения задаются в `config.py`:

```python
DB_HOST = "localhost"
DB_USER = "root"
DB_PASSWORD = ""
DB_NAME = "qrmenu"
```

### 4. Первый администратор

Пользователей с готовым паролем в базе нет. Сгенерируйте хеш пароля:

```bash
python scripts/generate_db_password.py
# или задайте свой пароль:
python scripts/generate_db_password.py --password "МойПароль123"
```

Добавьте пользователя с ролью `developer`, подставив полученный хеш:

```sql
INSERT INTO qrmenu.users (name, email, password_hash, global_role)
VALUES ('Admin', 'admin@example.com', '<хеш из скрипта>', 'developer');
```

### 5. Запуск

```bash
python app.py
```

- Главная страница: http://localhost:5000
- Меню ресторана: `http://localhost:5000/<slug>`
- Админ-панель: http://localhost:5000/admin/login

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | Ключ подписи сессий. Без него ключ генерируется при каждом запуске, и после перезапуска все пользователи выходят из системы. |
| `SESSION_COOKIE_SECURE` | Любое непустое значение включает флаг `Secure` у cookie. Нужно при работе через HTTPS. |

## Продакшен

`python app.py` запускает встроенный сервер Flask в режиме отладки на `0.0.0.0:5000`. Этот режим подходит только для разработки. Для публичного сервера:

- Запускайте приложение через WSGI-сервер (gunicorn, waitress) за nginx или другим обратным прокси
- Задайте постоянный `SECRET_KEY` и включите `SESSION_COOKIE_SECURE`
- Создайте отдельного пользователя MySQL с паролем, а не работайте под `root`

## Структура проекта

```
app.py                  точка входа: публичные страницы ресторана
config.py               параметры подключения к MySQL
api/
  admin.py              админ-панель (/admin)
  menu.py               публичный JSON API меню и аналитики
database/
  db.py                 подключение к MySQL
  analytics.py          запись посещений и событий корзины
services/
  qr_pdf.py             генерация QR-кода и PDF для печати
scripts/
  generate_db_password.py  генератор хеша пароля
sql/                    схема базы и миграции
static/                 CSS, JS, иконки флагов, загруженные изображения
templates/              Jinja-шаблоны (публичные страницы и admin/)
```

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/<slug>/menu` | Ресторан, категории и блюда в JSON |
| GET | `/api/menu` | То же для первого активного ресторана |
| POST | `/api/analytics/cart-add` | Событие добавления в корзину: `{restaurantId, menuItemId, quantityDelta}` |
